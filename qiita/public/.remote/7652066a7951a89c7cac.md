# 詳細 #

## <a name="chap0"></a> セットアップ ##

    $ rvm use ruby-2.0.0-p247
    $ rvm gemset create sinatra
    $ rvm use ruby-2.0.0-p247@sinatra
    $ gem install bundler
    $ bundle init
    $ bundle

## <a name="chap1"></a> アプリケーションサンプル1 ##

### プログラム作成 ###

+ [server.rb](sample1/server.rb)

        require 'sinatra'
    
        get '/' do
         "Hello, world!"
        end

### プログラム実行 ###

    $ ruby sample1/server.rb

### プログラム確認 ###

    http://localhost:4567/
